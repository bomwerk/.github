# Getting help

- **Documentation:** [bomwerk.com/docs](https://bomwerk.com/docs/) and the [capability ledger](https://github.com/bomwerk/bomwerk/blob/main/docs/capabilities.md), which lists what works today.
- **A bug or an accuracy problem:** open an issue on the repository concerned. Include what you ran, the output, and `bomwerk --version`.
- **Anything else, including Pro and design partners:** write to [hello@bomwerk.com](mailto:hello@bomwerk.com).
- **A security problem:** do not use issues or hello@. Follow the [security policy](SECURITY.md), which uses info@bomwerk.com as the fallback.
