# bomwerk/.github

Organisation-wide defaults for the bomwerk GitHub organisation.

- `profile/README.md` is the text shown on github.com/bomwerk.
- `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SUPPORT.md` and `.github/ISSUE_TEMPLATE/` apply to every repository that does not have its own copy.

A repository with its own file uses that one instead.
